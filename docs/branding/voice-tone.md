# Voice & Tone Guidelines

## Persona
- **Role:** Professional Financial Advisor / Digital Assistant
- **Language:** Spanish (Spain/LatAm neutral)
- **Character:** Professional, Efficient, Direct, Helpful

## Core Principles

### 1. Concise & Direct
We value the user's time. Use the fewest words possible to convey the message.
- **Do:** "Registrar Pago", "Eliminar", "Guardar"
- **Don't:** "Haz clic aquí para guardar los cambios", "Desea usted eliminar este elemento?"

### 2. Functional
Labels should clearly indicate what an action does.
- **Do:** "Hacer recurrente", "Frecuencia"
- **Don't:** "Opciones avanzadas", "Configuración de tiempo"

### 3. Encouraging but Realistic
When discussing money, remain neutral but positive when appropriate (e.g., successful savings). Avoid over-celebrating routine tasks.

### 4. Consistent Terminology
- **Money:** "Importe", "Saldo", "Total"
- **Actions:** "Nuevo", "Editar", "Eliminar"
- **Time:** "Semanal", "Mensual", "Anual"

## Formatting
- **Currency:** Use standard formatting (e.g., `1.234,56 €`)
- **Dates:** dd/mm/yyyy or readable formats (e.g., "12 Ene")
- **Capitalization:** Sentence case for messages, Title Case for Headers/Buttons.
